# Manual ChatGPT annotation packets (evidence-window)

Generated by `scripts/make_chat_annotation_packets.py`. Manual (non-API) workflow.

Each article's `article_text_for_review` is a compact evidence packet: beginning + ending
context plus a few lexical-trigger windows from the collapsed codebook (short articles are
included whole). The `[EVIDENCE WINDOW n | retrieval_hint=... | trigger="..."]` markers are
retrieval scaffolding, NOT labels — annotate only from the visible text.

## Contents

- `annotation_prompt_base.md` — the annotation prompt (also embedded in every packet).
- `packets/chat_packet_NNN.md` — paste/upload ONE packet at a time into ChatGPT.
- `packets/chat_packet_NNN.json` — the same article objects (incl. `retrieval_hints`).
- `codebook.json` — paste once at the start of the session for the code definitions.
- `manifest.csv` — one row per article (packet, position, strategy, hint codes).
- `results/` — drop ChatGPT replies here (you create these files).

## How to annotate

1. Paste `codebook.json` into ChatGPT once at the start of the session.
2. Open `packets/chat_packet_001.md`, copy its full contents, and paste into ChatGPT.
3. ChatGPT returns a JSON array (one object per article_id).
4. Save that reply verbatim to `results/chat_packet_001_results.json`.
5. Repeat for `chat_packet_002.md`, `003`, ... one packet per message.

## How to merge back

```
python scripts/merge_chat_results.py \
  --results-dir chat_annotation_packets_jaleo/results \
  --manifest-csv chat_annotation_packets_jaleo/manifest.csv \
  --out-csv chat_annotation_packets_jaleo/merged_chat_annotations.csv
```
